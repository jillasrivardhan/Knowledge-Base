# 📚 Knowledge Base

A curated **technical learning and interview-preparation knowledge base** containing reference material across aptitude, programming, web development, machine learning, deep learning, and system design.

This repository brings together study resources in one place so learners can use it for **concept revision, interview preparation, coding practice, and structured self-learning**.

## ✨ What This Repository Contains

| Category                   | Resources | Focus                                                   |
| -------------------------- | --------: | ------------------------------------------------------- |
| 🧠 Aptitude & Logic        |         2 | Quantitative aptitude, reasoning, and logic building    |
| 💻 Coding & Programming    |         2 | Coding practice and programming interview preparation   |
| 🌐 JavaScript & React      |         2 | Frontend development concepts and interview questions   |
| 🧩 OOP & Interviews        |         1 | Object-oriented programming and interview preparation   |
| 🤖 Machine Learning        |         1 | Machine learning concepts and practical understanding   |
| 🧠 Deep Learning           |         2 | Neural networks and deep learning concepts              |
| 🗄️ Data-Intensive Systems |         1 | Designing and understanding data-intensive applications |

## 📌 Recommended Usage

Use the repository as a **reference library**, not as a replacement for hands-on practice.

For the best results:

1. Read the relevant concept.
2. Write your own notes.
3. Solve related questions without looking at the answers.
4. Build a small project using the concept.
5. Revisit interview questions during revision.
